# Bias Insights Hub

Build a modern web application called “BiasCheck” for MBA students.

Purpose:

Help students analyze business opinions and detect cognitive biases in case discussions.

Core Features:

Case Discussions

Users can create or join case discussions and post their opinions about business decisions.

AI Bias Detector

When a user posts an opinion, AI analyzes the text and highlights possible cognitive biases such as confirmation bias, anchoring bias, survivorship bias, or herd mentality.

Perspective Generator

AI suggests alternative viewpoints or strategic considerations that the user may have missed.

Debate Mode

Automatically generate arguments for and against a decision to encourage balanced thinking.

Dashboard

Shows trending cases, most debated topics, and diversity of opinions.

Tech Stack:

Use Supabase for authentication, PostgreSQL database, and realtime updates.

Use Supabase storage for case documents.

Integrate an AI API for text analysis.

Build a clean modern dashboard UI.
